No tienes acceso. Pide que te añadan a la afiliación en GitHub.
Tu llave personal. Se envía solo a GitHub.
Desmárcalo si usas un ordenador compartido.
¿Cómo consigo mi token?
  1. En GitHub, pulsa tu foto → Settings → Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Resource owner elige la organización de la afiliación.
  4. Repository access: Only select repositories → actividades.
  5. Permissions → Issues: Read and write.
  6. Pulsa Generate token, cópialo y pégalo aquí.
